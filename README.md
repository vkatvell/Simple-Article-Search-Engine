
# Search Engine

Built by Venkat Vellanki and Noah Henson.

A simple boolean query processor that ranks 50,000 JSON financial articles based on term frequency and inverse document frequency (TF-IDF) and returns the most relevant articles as a search result. This system uses an AVL tree to serve as an inverted file index of the relevant words from an input of 300,000 documents.

Kaggle Financial News Dataset: [Kaggle](https://www.kaggle.com/datasets/jeet2016/us-financial-news-articles)
